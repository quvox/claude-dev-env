# migrations/ — 版を上げたときに、上書き展開では直らないもの

**1件 = 1ファイル。** 書式と当て方の正は `.claude/skills/kit-migrate/SKILL.md` である
(ここには写さない)。当てるのは `/kit-migrate`、どれが要るかを判定するのは
`.claude/scripts/kit-migrate.py` である。

**ここに載るのは、配布物を上書きしても直らないものだけである** — 記録ファイルの引っ越し、
配布物に含まれない設定ファイルへの追記、プロジェクトが自分で持っている宣言の作り直し。
展開で直るものを載せると、済んでいる移行が毎回並ぶ。
