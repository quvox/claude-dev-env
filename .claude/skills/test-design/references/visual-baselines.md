# 見え方の基準 — 画面写真を期待値として持つ

**規範の正は `.claude/directions/ux.md`「見え方の基準」である。** ここに書くのは、
そこで決めたことをテストの側でどう配線するかだけで、**規則そのものを写さない。**

保存済みの期待出力(golden)の画像版である。違いは1つだけ — **合否を左右しない**(下の §3)。

## 1. 置き場 — 入力と出力を混ぜない

```
tests/visual/baselines/SCR-01/初期.png      ← 入力。人がレビューして決めた期待値。git で追跡する
tests/visual/baselines/SCR-01/エラー.png
artifacts/<run-id>/visual/SCR-01/初期.{baseline,actual,diff}.png   ← 出力。git に入れない
```

判断軸は `references/golden.md`「git 管理する」とまったく同じである:
**入力か出力か。** 基準の画像は見た目こそ出力だが、役割は**人が決めた期待値**なので
`tests/` の中に置いて git で追跡する。撮り直した今回の画面と差分は出力なので
`artifacts/<run-id>/` へ出す(置き場の規則の正は `.claude/directions/flows.md` §2)。

**`tests/.gitignore` で基準の画像を除外しない。** `**/*.actual` などの作業ファイルと
同じ扱いにすると、基準が git に入らず、比較する相手が誰の手元にも無くなる。

## 2. 撮るのはテストの側である

**`test-runner` は画面写真を撮らない**(`references/evidence-wiring.md` の冒頭と同じ)。
ランナーがするのは出力先を子プロセスへ渡すことだけで、撮影も比較も各テストの道具の機能である。

- **撮る状態を決めて名前にする** — 「初期」「エラー」「空」のように、`screens/` の
  「状態」の節に書いた状態の名前をそのまま使う。**画面1つにつき1枚とは限らない。**
- **揺れる部分を止めてから撮る** — 時刻・乱数・アニメーション・読み込み中の表示。
  止めずに撮った基準は、次の実行で必ず差分を出し、**差分が常態になると誰も見なくなる。**
- **撮る条件を固定する** — 画面の大きさ・言語・テーマ・権限。条件が変われば別の基準である。

## 3. ★ 落とさない形で配線する

**画面写真の一致判定で試験を落とさない**(`ux.md`「見え方の基準」の裁定)。
多くのテストの道具は、画像比較の機能を**既定で失敗にする**ので、**そのまま使うと裁定に反する。**
落とさない形は道具によって違う(比較だけ行って結果を書き出す / 失敗を握って報告に回す など)。
**どう配線したかと、実際のコマンドは `docs/02-design/environments.md` が正である。**

出すもの:

| 出すもの | 置き場 |
|---|---|
| 差が出た画面と状態の一覧 | 実行の要約(人が最初に読むところ) |
| 基準・今回・差分の3枚 | `artifacts/<run-id>/visual/<画面 ID>/` |

**裁定を書く。** 「画像比較は合否に入れない」という選択は `DS-01` の判断であり、
`03-impl/tests/strategy.md` の「テスト設計の判断」に1行で開示する
(書式の正は `.claude/directions/delegation.md` §3)。

## 4. 更新できるのは人間が明示したときだけ

golden と同じである(`references/golden.md`、更新の権限は `DS-01`)。
**AI が黙って基準を上書きできるなら、壊れた画面がそのまま次の基準になる。**

- 更新は人間の明示指示のときだけ(`--update-golden` に相当する口を、同じ扱いで持つ)。
- **差分を消すために基準を撮り直すことは、直したことにならない。**
  意図した変更かどうかを決めるのは依頼元と人間であり、テストでもAIでもない。
- 更新したら、**何の画面のどの状態を、なぜ更新したかを報告に書く。**

## 5. 誰が読むか

- **`/build`** — 見え方が変わる直しをしたタスクは、**差が出た画面の一覧を報告に載せる**
  (`/build` §4)。裁定はしない。
- **`@qa`(探索的ブラウザQA)** — 差分は所見の材料である。ただし
  **差分が出たこと自体は所見ではない** — 実画面を見て、壊れているかどうかを言う。
