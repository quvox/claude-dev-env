- 結末: 回答(A を選択)

  次に出す1回を最初のリリース(`0.9.0`)とする**、と読んだ。この読みで A と矛盾しない。
  (もう一方の読み — 「いまこの場で記録を打つ」— は、A ではなく B の内容であり、かつ
  デプロイゲートが red のため実行できない。)
