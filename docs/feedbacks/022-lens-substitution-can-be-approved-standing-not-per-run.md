# 022 レンズの代替承認は「常設」でも与えられる

## 状況

CLAUDE.md 不変則7 は「レンズの無断代替は禁止。代替は独立性を下げるので**人間の判断**であり、
決定シートで問う(既定は**代替しない**)」と定める。この規定に従い、`/task-doc` と `/doc-check`
では毎回「Codex が使えない。サブエージェントで代替してよいか」を問い、人間が「A(代替する)」と
回答し、AI 側は**その承認を「当該1実行に限る」と明記して memo に記録**していた
(`memo.md`「決定シートの追加回答」節)。

`/implement` の開始時、人間は指示の冒頭でこう述べた:

> 今後、codex が利用できない時は subagent を使って。

## AI の提案

AI は不変則7 の「既定は代替しない」を厳格に読み、**承認は1実行ごとに失効する**という運用を
自分で作っていた(`memo.md:149`「この承認は**やり直す `/doc-check` の1実行に限る**。
次の実行・次のフェーズ(`/implement` / `/task-close`)には持ち越さない」)。

## 人間の判断とその理由

**判断を前もって、期限なしで与えた。** 理由は明示されなかったが、実質は明らかである:
Codex の復旧は 2026-08-11 で、それまでの全実行が同じ質問を繰り返すことになる。
不変則7 が禁じているのは**無断の代替**であって、**人間が判断を与えること自体**は
1実行分でも常設でも同じく有効である。「毎回問う」は不変則7 の要求ではなく、
AI が加えた上乗せだった。

## 今後どう活かすか

- **承認の有効範囲は、承認した人間が決める。** AI が勝手に「1実行限り」へ狭めない。
  人間が範囲を言わなかったときだけ、既定として当該1実行と解釈する。
- **常設の承認があっても、省略してよいものは「問うこと」だけである。** 次の3つは残る:
  (a) **まず Codex を実際に起動して不可を確認する**(不可の理由も記録する)、
  (b) レポートに **`lens: subagent`** と実際のモデル名を明記する(Codex の監査として提示しない。
  不変則7 後段)、(c) **レンズを省略しない**(代替を断ることと E2E・監査を断ることは別である)。
- 同型の一般化: **人間の判断を「安全側」に読み替えて狭めるのも、勝手な解釈である。**
  広げる方向だけでなく狭める方向にも、根拠のない上乗せをしない。
- この常設承認は会話の中で与えられたため、**セッションをまたぐと失われる**。
  規範として残すべきかは `docs/issues/065` で追跡する。
