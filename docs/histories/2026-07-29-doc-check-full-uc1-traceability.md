# 変更記録:/doc-check full の指摘修正（UC-1 の関連要件に要件5・要件11 を補完）

## 変更理由・背景

新規セッションで `/doc-check full` を実施し、A1（UC 網羅）の突合で 1 件の追記漏れを検出した。
UC-1 の基本フロー2 は「認証・ファイアウォール・（VNC ありなら）ブラウザ環境を設定し」と述べており、
要件5（ネットワーク隔離とファイアウォール）と要件11（ブラウザ確認）はフロー本文には現れているが、
`関連要件` 行には要件1・2・4 しか挙がっていなかった。要件→UC の追跡は `関連要件` を経由するため、
この 2 件が追跡表から抜け落ちていた。

あわせて、実コード `claude-dev`（1387 行）の構造変化により 03-impl/cli.md の行番号参照が
実装とずれていたため更新した（意味は変えていないため PATCH）。

## 変更内容の要約

- **01-requirements/core.md（1.4.0→1.5.0）**: UC-1 の `関連要件` に要件5（基本フロー2 の
  ファイアウォール設定）と要件11（同 VNC ありのブラウザ環境）を追記した。フロー本文が既に
  述べている内容の追跡情報の補完であり、要件そのものの追加・変更はない。
- **03-impl/cli.md（1.5.0→1.5.1, PATCH）**: 節見出しとエラーハンドリング表の行番号参照を
  実コードへ合わせた（初期化・定数 L1〜59／ヘルパー関数群 L61〜417／case ディスパッチ
  L422〜1387／tmux 起動タイムアウト L882〜／`/dev/kvm` 不在 L643）。
