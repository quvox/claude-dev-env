# 2026-09-06 UI/UX の記述を 02-design から docs/ux/(UX 文書)へ移す

## 変更理由

### R-01 UI/UX の記述の置き場が新設され、02 に残っていた中身の引っ越しが要った

- 起点層・根拠: 02-design。人間の要望(`.claude/missions/2026-09-06-kit-migrate/requests.md`
  2026-09-06 08:16 / 002 の項目b)と `.claude/migrations/2026-08-28-docs-ux.md`。
- 変更が必要になった条件: 2026-08-28 に `docs/ux/` が新設され、UI/UX の記述は文書整合検証・
  実装整合検証の依存の外(qa 試験区分の依存の中)へ移った。このプロジェクトは 02 に UI 設計の
  中身を持ったままだったので、UI/UX の小さな修正のたびに 02 の鮮度スタンプが失効し続けていた。

## 変更内容の要約

- `docs/ux/` を新設し、02 の UI設計節が持っていたデザイン方針・画面一覧の台帳・
  SCR-01 の項目と状態を移送した。02 の UI設計節は `DSN-ui-01` と UI の有無の宣言だけになった。
- 移送のさい、散文の条項参照(「`FR-env-01` 受入基準16」)を条項 ID 形(`FR-env-01-16`)へ
  直した。`check-ux.py` UX1 が実在と未退役を見られる形にするためで、指す先は変えていない。
- 03 から SCR-01 を指していた参照1本を移送先へ張り替えた。
- `docs/README.md` に `ux/` の位置づけ・ツリー・読み場所の2行を足した。
