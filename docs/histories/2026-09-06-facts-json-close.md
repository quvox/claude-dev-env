# 2026-09-06 事実一覧ファイル `docs/facts.json` を空の宣言として置く

## 変更理由

### R-01 判断待ちのまま並び続けていた移行を、正しい終わり方の一方で閉じる

- 起点層・根拠: 人間の要望(2026-09-06 08:16「1,2に対応して。.gitignoreも適切に修正して」。
  項目1 =「キット移行が判断待ちのまま残した4件(facts.json / docs/ux(SCR-01) /
  releases.json / record-terms)」)。移行の手順は
  `.claude/migrations/2026-08-27-facts-json.md` が持つ。
- 変更が必要になった条件: 2026-08-27 にキットへ入った事実の生成器 `build-facts.py` は、
  何を機械の欄に出すかの宣言を `docs/facts.json` から読む。この宣言は配布物ではないので
  上書き展開では入らず、置かないかぎり `/kit-migrate` はこの移行を毎回「要る」と出し続け、
  並んでいることの意味が失われる。

## 変更内容の要約

- `docs/facts.json` を `{"facts": []}` として新規に置いた。
- 判断の中身: `docs/` の中に、この道具が埋める機械の欄
  (`<!-- BEGIN GENERATED: build-facts.py id=... -->`)は現時点で**1つも無い**
  (`grep -rn "BEGIN GENERATED: build-facts" docs/` が一致0件)。埋める先が無い以上、
  宣言できる事実も0件であり、移行ファイルが★付きで正しい終わり方と定める手順②
  (空で置いて閉じる)を採った。
- 移行 `2026-08-27-facts-json` は `kit-migrate.py list` で `[不要]` に変わった
  (`detect: test -d docs && test ! -f docs/facts.json` が偽になったため)。
