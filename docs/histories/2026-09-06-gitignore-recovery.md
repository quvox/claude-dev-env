# 2026-09-06 `.claude/` を git の追跡へ戻す(資格情報は許可リストで機械的に締め出す)

## 変更理由

### R-01 `.claude/` 配下が git に1件も追跡されていない

- 起点層・根拠: 人間の要望(2026-09-06 08:16「1,2に対応して。.gitignoreも適切に修正して」)。
  `docs/residual.md` に 2026-09-01 から同じ指摘が1行あった。
  `CLAUDE.md` §4 は `.claude/state/stamps.json` を git で追跡すると定めているが、
  `.gitignore:4` の `.claude` により `.claude/` 配下は**一度も**追跡されていなかった
  (`git log --all -- .claude` が空)。追跡されないと、複製先・CI・別チェックアウトで
  デプロイゲートが「スタンプ皆無」と判定する。
- 変更が必要になった条件: `.claude` の行は 2026-03-31 commit 36a1a89 で入っており、
  キットが `.claude/` へ入居するより前である。後から入居したキットを、先に在った ignore が
  黙って飲み込んでいた。

### R-02 未コミットの `.colabtmux` の編集が効いていない

- 起点層・根拠: 作業指示が「精査し、意図と衝突しないよう整理する」ことを求めた。
  未コミットの `!.colabtmux/colabtmux.conf` は、その上の `.colabtmux/` が
  ディレクトリごと除外するため**決して効かない**(`git check-ignore -v` が
  `.gitignore:14:.colabtmux/` を返して実証)。
- 変更が必要になった条件: `.colabtmux/colabtmux.conf:1` が
  「このファイルはコミットして共有する」と自ら宣言しており、意図と実際が食い違っていた。

## 変更内容の要約

- ルートの `.gitignore` に `.claude/` の**許可リスト**(既定で全部除外し、名前を挙げたものだけ戻す)を置いた。
  除外リストにしない理由は `.claude/scripts/kit-dist.json` の `_comment` と同一である —
  挙げ忘れが事故になる側ではなく、挙げ忘れが安全側へ落ちる形を選んだ。
- `.claude` の行は**消さずに残した**。`claude-dev start`(`claude-dev:1567`)が起動のたびに
  完全一致で有無を見て書き足すため、消すと次回起動で黙って戻る。次の行 `!/.claude/` で
  ディレクトリだけを打ち消し、git が中へ降りられるようにした。
- `.colabtmux/` を `/.colabtmux/*` に改め、`!/.colabtmux/colabtmux.conf` が実際に効くようにした。
- `CLAUDE.md` / `AGENTS.md` を `/CLAUDE.md` / `/AGENTS.md` に改めた。先頭の `/` が無いと
  どの階層の同名ファイルにも一致し、キットの雛形 `.claude/templates/AGENTS.md` まで巻き込む
  (実際に巻き込んでいたのを検出して直した)。ルート直下2本を外す 2026-08-02 commit 976960c の
  意図は変えていない。
