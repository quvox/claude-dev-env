# 2026-11-24 日次ビルド(GHCR)の失敗の修正

## 変更理由

### R-01 arm64 で Playwright の Chromium の置き場が chrome-linux-arm64/ になり、探索に当たらなくなった

- 起点層・根拠: 03-impl(構造は同じで、実装詳細だけが変わる)。人間の要望 2026-11-24「github actionsでエラーが出ている。原因を究明して、解決して」(`.claude/missions/2026-11-24-fix-ghcr-ci/requests.md`)
- 変更が必要になった条件: 2026-09-09 から日次ビルドの arm64 の claude-vnc が毎回「GUI 用 Chromium が見つかりません」で失敗し、`merge` が skipped になってどのイメージも公開されていなかった(最後の success は 2026-09-08 の run 34279906129)。Playwright が arm64 の Chromium を Chrome for Testing の `chrome-linux-arm64/` に置くようになり、`chrome-linux/` と `chrome-linux64/` だけを探す条件に当たらなくなった。同じ条件のヘッドレス用ランチャーの層は、見つからないと何もせずに通るため、arm64 の両イメージでランチャーと環境変数が黙って欠けていた。
- 2026-11-24 の回だけに出た「agy の版が指定と一致しません(指定 1.5.15 / 導入 1.5.16)」は、版の解決と導入のあいだに新版が出た一時的な事象で、`docs/03-impl/environments/images.md` の落とし穴の表に再実行で解決と既に載っている。直していない(やらないこと)。

## 変更内容の要約

- `.devcontainer/Dockerfile.claude` の2か所の探索条件を `-path "*/chrome-linux*/chrome"` へ広げた。
- ヘッドレス用ランチャーの層も、Chromium が見つからなければビルドを止めるようにした(GUI 用と揃えた)。
