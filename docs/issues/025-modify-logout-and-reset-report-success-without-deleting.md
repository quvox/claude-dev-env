# 025 `logout` / `reset` が消えていないのに成功と表示する

## 事象

**(1) 削除の失敗を握りつぶす。** `logout` の共有ボリューム消去は
`docker run … -c "rm -rf /auth/* /auth/.*" 2>/dev/null || true`(`claude-dev:645`〜`:648`)で、
**失敗しても必ず `✅ 認証情報を削除しました` と表示して 0 で終わる**。
`reset` も全削除ステップが `2>/dev/null || true` で、最後に `✅ 全リセット完了` と表示する
(`claude-dev:1385`〜`:1397`)。**失敗した項目は一覧されない。**

**(2) プロジェクト配下の認証コピーを消さない。** `start` は認証を
`${PROJECT_DIR}/.claude/.credentials.json` / `.claude.json` と `${PROJECT_DIR}/.codex/auth.json` へ
**コピー**する(`claude-dev:749`〜`:766`)。`logout` / `reset` はどちらも共有ボリュームだけを対象にし、
**プロジェクト配下のコピーは残す**(`reset` は「利用者のリポジトリを触らない」という実装上の判断)。
その結果、`logout` 後に同じディレクトリで `claude-dev start` すると**残っていたコピーで
そのまま認証済みになる**。

再現手順:

1. `claude-dev login` してから任意のディレクトリで `claude-dev start` する(認証がコピーされる)。
2. `claude-dev logout` を実行する → `✅ 認証情報を削除しました` と表示される。
3. `${PROJECT_DIR}/.claude/.credentials.json` が残っていることを確認する。
4. 再度 `claude-dev start` すると認証済みで起動することを確認する。

## 影響

- **`FR-env-03` の「以後のコンテナが未ログイン状態で起動する」が満たされない。**
- 認証情報(OAuth の資格情報)が、利用者が削除したつもりのあとも**ワークツリー配下に残る**。
  `.gitignore` に `.claude` / `.codex` は自動追記されるためコミットは防がれるが、
  バックアップ・同期ツール・コンテナ間共有の経路では残存が問題になりうる。
- 表示は成功時と同一(`✅` + 終了コード 0)なので、**利用者は失敗に気づけない**。

severity を「中」とした根拠: 秘密が外部へ送信されるわけではなく、手で削除すれば回復する。
一方で「ログアウトした」という利用者の期待を静かに裏切る。

## 原因の見当

推測: 片付け処理は「途中で止まらないこと」を優先して全ステップの失敗を握る方針にした
(`MODULE-cli-stop` / `-reset` / `-logout` に共通)。表示はステップの成否と結び付いていない。
プロジェクト配下のコピーは `reset` の実装上の判断2(利用者のリポジトリを触らない)に従った結果で、
`logout` にも同じ判断が波及している。

## 正はどちらか

| 観点 | 実装(03)はどう言っているか | 要件・設計(00〜02)はどう言っているか | 判定 |
|---|---|---|---|
| 削除の失敗の扱い | 握りつぶして成功と表示する | `02-design/logging.md` は「処理を続けられず終了する失敗は ERROR で、原因と次の操作をセットで出す」と定める | **設計が正** |
| プロジェクト配下のコピー | 消さない(リポジトリを触らない) | `FR-env-03` は「以後のコンテナが未ログイン状態で起動する」ことを求める | **設計が正**(ただし「リポジトリを触らない」との両立方法は要検討) |

## 対処案

| 案 | 内容 | 影響範囲の見込み |
|---|---|---|
| A | 各削除ステップの終了コードを見て、失敗した項目を一覧表示する(全体は続行。最後の表示を「一部失敗」に切り替える) | `claude-dev` / `claude-dev-mac` の `logout` / `reset`、`MODULE-cli-logout` / `-reset` |
| B | A に加えて、`logout` が**カレントディレクトリの** `.claude/.credentials.json` / `.claude.json` / `.codex/auth.json` も削除する(他ディレクトリは対象外。削除したパスを表示する) | 同上 + `FR-env-03` の受入基準 |
| C | 現状を仕様として確定させ、`FR-env-03` に「プロジェクト配下のコピーは利用者が消す」と明記し、`logout` がその手順を表示する | ドキュメント + 表示文の追加 |

推奨は **B**(利用者の期待に沿い、他ディレクトリには触らない)。
