# 028 名前の一意性が `NFR-scale-01` を満たしていない

## 事象

`NFR-scale-01` は**プロジェクト間で名前が衝突しないこと**(衝突 0 件)を求める。しかし同一性は
すべて「文字列としての名前」だけで決まり、**パスを区別する情報が入っていない**。

| 名前 | 決め方 | 衝突する例 |
|---|---|---|
| コンテナ名 | `basename $(pwd)` を小文字化し `[a-z0-9._-]` 以外を `-` に置換(`claude-dev:245`〜`:247`) | `~/a/web` と `~/b/web` が**同一セッション扱い**になる(`start` は既存コンテナへ再接続する) |
| compose プロジェクト名 | 上をさらに `[a-z0-9_-]` 以外を `-` に置換(`claude-dev:820`) | `My.App` と `my-app` が同じ `my-app` になる(`docs/issues/024` の削除巻き込みの原因) |
| 中継コンテナ名 | `fwd-<NAME>-<cport>`(`claude-dev:1167`) | `forward <port> <NAME>` で他プロジェクトの中継名と一致させられる |
| Chrome / VM ボリューム | `claude-dev-chrome-<NAME>` / `claude-dev-vm-<NAME>` | 同名ディレクトリ間でプロファイル・ゲストディスクを共有してしまう |

再現手順:

1. `~/a/web` で `claude-dev start` する。
2. 別パスの `~/b/web` へ移動して `claude-dev start` する。
3. **新しいコンテナが作られず、`~/a/web` のセッションへ接続される**ことを確認する
   (`/workspace` は `~/a/web` を指したまま)。

## 影響

利用者は `~/b/web` の環境を起動したつもりで、**別のディレクトリをマウントしたコンテナで作業する**。
編集先を誤る可能性があり、Chrome プロファイルと VM ゲストディスクも共有される。
`NFR-scale-01` の「衝突 0 件」という受入基準に対して**不一致**であり、
`D0-scope-07` の起票の閾値 (a)「01・02 の記述との不一致」に当たる(気づけるかどうかとは独立)。

severity を「中」とした根拠: 同名ディレクトリを複数扱う運用でのみ起きる。ただし起きたときは
作業先を誤るため被害が大きい。

## 原因の見当

推測: 「1ディレクトリ = 1セッション、名前はディレクトリ名」という分かりやすさを優先した
(`D0-scope-02`)。`NFR-scale-01` は**ポートとプロファイルの一意化**は満たしている(空きポート探索と
コンテナ別ボリューム)が、**名前そのものの一意化**は誰も担保していない。

## 正はどちらか

| 観点 | 実装(03)はどう言っているか | 要件・設計(00〜02)はどう言っているか | 判定 |
|---|---|---|---|
| 名前の一意性 | 「コンテナ名がディレクトリ名だけで決まる」「中継コンテナ名の一意性が文字列だけで決まる」と**既知の制限**として記述 | `NFR-scale-01`「名前・ポート・プロファイルの一意化で衝突を避ける」 | **設計が正**(実装が一意化を保証していない) |

## 対処案

| 案 | 内容 | 影響範囲の見込み |
|---|---|---|
| A | 名前に**絶対パスのハッシュ短縮値**を足す(例: `web-3f2a1b`)。コンテナ名・compose 名・中継名・ボリューム名を1つの関数から導く。既存セッションは移行手順が必要 | `claude-dev` / `claude-dev-mac` の名前生成、`CTR-cli-container`、`MODULE-cli-start` / `-stop` / `-forward` / `-list`、`docs/issues/024` も同時に解消する |
| B | 衝突を**検出して警告する**(既存コンテナの `/workspace` のマウント元が現在のパスと違えば、再接続せずに警告して中止する) | `claude-dev` の `start` 冒頭、`MODULE-cli-start` |
| C | `NFR-scale-01` の受入基準を「**異なるディレクトリ名**のプロジェクト間で衝突しないこと」に狭める(実装を正とする) | `01-requirements/non-functional.md` と 03 の該当行 |

推奨は **B**(小さく、誤った作業先を防げる)。根本解決は A。
