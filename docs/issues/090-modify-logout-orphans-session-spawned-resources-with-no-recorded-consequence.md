# 090 `logout` が作る孤児のセッション由来資源が、どこにも記録されていない

## 事象

`docs/00-requests/decisions/env.md`(`D0-env-05` 項2)は、セッション由来の資源の片付けについて

> **`claude-dev logout` には掛けない**(認証を消す操作であり、実行中のコンテナ群まで消すのは
> 利用者の期待を超える)。

と書く。しかしこの理由は「`logout` は実行中のコンテナを消さない」を前提にしている。
実際には `FR-env-03` 受入基準17 と `CTR-cli-container` の規則 A により、
**`logout` は管理ラベルを持つ Claude コンテナを集合として削除する**
(実装は `claude-dev:1041` 付近の `docker rm -f`)。

所有者コンテナが消えると、`FR-env-01` 受入基準23 により
`claude-dev stop <name>` は「対象コンテナが既に存在しない」として
**セッション由来の資源の片付けを一切行わない**。したがって `logout` のあとは、
そのセッションが作ったコンテナ・ネットワークの回収手段が **`claude-dev reset` と手動だけ**になる。

この帰結が 00・01・02・03 のどこにも書かれていない(「既知の制限」にも、利用者への表示にも無い)。

## 影響

`logout` を使う利用者は、片付けたつもりで回収不能な資源をホストに残す。
`D0-env-05` 項2 が守ろうとした「セッションが作ったものは全部片付ける」が
`logout` 経由でだけ破れる。severity は「中」(データは壊れないが、決定の前提が事実と違う)。

## 原因の見当

`D0-env-05` 項2 の `logout` の除外は、片付けの範囲が compose 資源だけだった時期に書かれ、
2026-08-07 にセッション由来の資源へ広げたときに理由の側が見直されなかったと推測する(推測)。

## 正はどちらか

| 観点 | 実装(03)はどう言っているか | 要件・設計(00〜02)はどう言っているか | 判定 |
|---|---|---|---|
| `logout` が所有者コンテナを消すこと | 消す(`MODULE-cli-logout` 手順4 / 規則 A) | `D0-env-05` 項2 の理由は「実行中のコンテナ群まで消すのは期待を超える」と書く | **要確認**(00 の理由を書き直すか、`logout` にも片付けを掛けるか。どちらも人間の決定) |

## 対処案

| 案 | 内容 | 影響範囲の見込み |
|---|---|---|
| A | `D0-env-05` 項2 の理由を実態に合わせて書き直し(「認証を消す操作なので**セッション由来の資源までは追わない**。所有者コンテナは消えるので回収は `reset` と手動になる」)、02 の `CTR-cli-container` と 03 の `MODULE-cli-logout`「既知の制限」へ限界として1行ずつ足す | 00 1箇所 + 02 1箇所 + 03 1箇所。コードは不変 |
| B | `logout` にも規則 D を掛ける(所有者を問わず消す = `reset` と同じ) | 00 の決定変更 + `MOD-cli-logout` の実装。`logout` の意味が変わる |
| C | `logout` 実行時に「セッション由来の資源が回収できなくなる」旨を表示する | 00 は不変。02 の logging.md + `MOD-cli-logout` の実装 |

推奨は A(00 の理由だけが事実とずれており、振る舞いは変えなくてよい)。**ただし 00 の意味に
触れる編集なので人間の裁定が要る**(`.claude/directions/delegation.md` §1 の問う基準)。

## 人間の裁定(2026-08-07)— 案 A で確定。書く層は4つに分かれる

**回答は A**。あわせて人間の指示(「どの層に書くのかを考えよ」)により、**A の内容を層ごとに分解した**。
**上の案 A の「影響範囲の見込み」欄(00 + 02 + 03 の3箇所)は 01 を落としている** — `logout` 後に
`stop` が片付けられなくなることは**外から観測できる帰結**であり、`.claude/directions/01-requirements.md`
の置換テスト(実現方式を差し替えても真であってほしいか)にも観測者テスト(内側を見ずに確かめられるか)
にも掛かる。したがって次の表が正である。

| # | 何を書くか | 層 | 具体的な置き場 | なぜその層か |
|---|---|---|---|---|
| 1 | 「認証を消す操作なので、利用者が作った資源までは追わない」という**決定と、その理由** | **00** | `docs/00-requests/decisions/env.md`(`D0-env-05` 項2 の理由文の置き換え) | 人間が下した判断そのもの。**現行の理由文「実行中のコンテナ群まで消すのは利用者の期待を超える」は偽である**(`logout` は管理ラベルを持つ Claude コンテナを実際に削除する)。偽の理由を残すと、次に範囲を変える人が誤った前提から出発する |
