## AC-07 用意した外部実行ファイルがコンテナ内でそのまま使える

- 対応要求: RQ-dist-02
- 前提: 保守者が、同梱したい実行ファイル(Linux 向け)を手元に持っている。
- 操作:
  1. 保守者が、その実行ファイルをリポジトリの同梱用ディレクトリ(`externals/`)へコピーし、
     配布イメージを**ブラウザ確認あり/なしの両方**ビルドする。
  2. 保守者が、ビルドしたそれぞれのイメージの中で、そのツールの名前をそのまま打つ。
- 期待される結果: **どちらの構成のイメージでも**、場所を指定せずツール名だけでそれが起動する。
  以後そのイメージを使う開発者の側では、導入作業も設定も要らない。
  **CPU アーキテクチャごとに別の実行ファイルを用意した場合は、それぞれのアーキテクチャの
  イメージに、そのアーキテクチャ向けのものだけが入っている。**
  同梱用ディレクトリに何も置かなかった場合でも、イメージのビルドは今までどおり成功する。
- こうなったら不合格: コンテナの中でツール名を打っても見つからない / 場所を指定しないと
  起動できない / 一方の構成のイメージにしか入っていない / **別のアーキテクチャ向けの
  実行ファイルが入っていて起動できない** / 同梱用ディレクトリが空だとイメージのビルドが失敗する。
