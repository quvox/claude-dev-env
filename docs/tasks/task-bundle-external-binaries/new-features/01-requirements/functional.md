## FR-env-13 同梱外部バイナリ

- 対応要求: RQ-dist-02 / AC-07
- **分割可否: 不可分**
- 内容: 保守者が用意した**同梱外部バイナリ**(用語集)が、配布イメージ2種の
  どちらのコンテナ内でも、開発者の追加作業なしにコマンド名だけで起動できること。
  **何をどこへ用意するか(置き場とその規約)と、イメージ内のどこへ設置するかは 02/03 が定める。**

受け入れ基準(EARS):

| 条項 ID | 種別 | 基準 |
|---|---|---|
| FR-env-13-1 | 正常系 | WHEN 配布イメージをビルドするとき、システムは用意された同梱外部バイナリを、**ブラウザ確認あり/なしの両方の配布イメージ**へ、コンテナ内で**場所を指定せずコマンド名だけで起動できる状態**で設置しなければならない(用意する場所とその規約、イメージ内の設置先は 02/03 が定める) |
| FR-env-13-2 | 正常系 | WHEN 同梱外部バイナリを設置したとき、システムはそれを**コンテナ内の利用者がコマンド名だけで実行でき、かつ非特権の操作では書き換えられない**状態にしなければならない(権限と所有者の具体は 02/03 が定める)。**コンテナ内の利用者は特権昇格の手段を持つため、意図的な置き換えまでは防がない** |
| FR-env-13-3 | 正常系 | WHERE 特定の CPU アーキテクチャ向けに用意された同梱外部バイナリがある場合、システムはそれを**そのアーキテクチャの配布イメージにだけ**設置しなければならない。WHERE アーキテクチャを問わず用意されたものがある場合、システムは**すべてのアーキテクチャの配布イメージ**へ設置しなければならない(用意の仕方で両者を区別する方法は 02/03 が定める) |
| FR-env-13-4 | 境界値 | IF 用意された同梱外部バイナリが1件も無いならば、システムはイメージのビルドを失敗させてはならず、**何も設置せずにビルドを完了**しなければならない [DS-02] 何も置かれていない状態を正常として扱う — 理由: 同梱は任意の仕組みであり、何も同梱しない状態がこの仕組みの初期状態である。ここで失敗させると外部バイナリを使わない利用者のビルドが壊れる / 見直す条件: 特定の同梱物を要件が必須と定めたとき |
| FR-env-13-5 | 境界値 | IF 一方の CPU アーキテクチャ向けの同梱外部バイナリだけが用意されているならば、システムはもう一方のアーキテクチャのビルドを**失敗させても警告を出してもならない**(そのアーキテクチャのイメージには設置されない) [DS-02] 片側だけの用意を正常として扱う — 理由: 使うアーキテクチャが1つに限られる運用を仕様として認めるためであり、`FR-env-13-3` が「用意されたものだけを設置する」と定めた直接の帰結である / 見直す条件: すべてのアーキテクチャに同じ同梱物が入っていることを要件が求めるようになったとき |
| FR-env-13-6 | 異常系 | IF 用意された同梱外部バイナリの設置に失敗したならば、システムは**イメージのビルドを失敗させなければならない**(設置されないまま完了したイメージを公開してはならない) [DS-02] 設置の失敗を握りつぶさない — 理由: 欠けたイメージが公開されると、利用者はコマンドが見つからない理由に到達できず、公開したものは回収できない(`D0-dist-05` 項2)/ 見直す条件: 同梱物が任意であることを利用者が実行時に判別できる手段ができたとき |
