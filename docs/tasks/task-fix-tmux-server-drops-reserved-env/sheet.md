### 論点 2. env ファイルの値も tmux の窓へ届けるか、届けるならどの直し方にするか

- **選択肢**:

  - **B: tmux を起こすときの「ログインし直す」指定(`su -l` の `-l`)を外す。**
    載せ直しそのものが不要になり、コンテナに渡っている環境変数が**そのまま**引き継がれます。
    env ファイルの値だけでなく、時刻帯(`TZ`)と文字の並び順・書式(`LC_ALL`)も同時に直ります。
  - **C: 予約している名前以外もすべて載せ直す**(A の変種で、CLI からの受け渡しを要さない)。
