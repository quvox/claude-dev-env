## FR-env-03 認証の共有とセッション分離

- 対応要求: RQ-env-03 / AC-01 / AC-06
- **分割可否: 不可分**
- 内容: 一度のログインで全コンテナが認証を共有し、セッションと設定はコンテナごとに独立すること。
  同梱する両方のエージェント CLI(Claude Code / Codex CLI)について成り立つこと。
  **認証を削除する操作(`logout` / `reset`)が、確認なしに他プロジェクトの作業を落としたり、
  削除できていないのに成功を表示したり、消したつもりの認証をプロジェクト配下に残したりしないこと**
  (`D0-env-08` 項3〜5)。

| FR-env-03-23 | 異常系 | IF `logout` または `reset` が削除の途中で `INT` または `TERM` を受けたならば、システムは**進行中の1件を終えてから中断**し、**そこまでに削除した資源と未削除のまま残った資源を1件ずつ列挙**して**終了コード 130** で終わらなければならない。**「削除しました」「完了」と表示してはならない**(1件の削除を途中で切ると、より中途半端な状態が残る。`D0-env-08` 項5 の「失敗を握りつぶさない」は中断時にも及ぶ) |
| FR-env-03-24 | 境界値 | IF `claude-dev logout` が Claude コンテナを削除したならば、システムは**そのコンテナが所有していたセッション由来の資源を、以後の `claude-dev stop` の削除対象にしてはならず**(所有者を照合する値が失われるため。`FR-env-01` 受入基準23 と同じ根拠)、**それらの資源は `claude-dev reset` でのみ削除できる状態にしなければならない**(`logout` 自身はセッション由来の資源を削除しない — `D0-env-05` 項2)。**この状態を「削除できなかった資源」として表示してはならない**(受入基準18 の対象ではない。意図して範囲の外に置いたものである) |

## FR-env-04 SSH 鍵の限定転送

- 対応要求: RQ-env-01 / AC-01
- **分割可否: 不可分**
- 内容: プロジェクトごとに必要な SSH 鍵だけをコンテナへ渡し、秘密鍵ファイルは露出させないこと。

受け入れ基準(EARS):

| 条項 ID | 種別 | 基準 |
|---|---|---|
| FR-env-04-1 | 正常系 | WHEN コンテナを作成するとき、システムは SSH 秘密鍵ファイルをコンテナにマウントしてはならない(転送するのは agent ソケットだけであり、コンテナのライフサイクルのどの時点でも秘密鍵ファイルは渡らない) |
| FR-env-04-2 | 正常系 | WHERE プロジェクト直下の設定で使う鍵が指定された場合(設定の置き場と書式は 02/03 が定める)、システムはプロジェクト専用の ssh-agent を起動し、**指定された鍵だけ**を登録して転送しなければならない |
| FR-env-04-3 | 正常系 | WHEN `claude-dev ssh-keys` を実行したとき、システムは `~/.ssh` の鍵を対話選択させ、選択結果をプロジェクト直下の設定として保存しなければならない |
| FR-env-04-4 | 境界値 | IF プロジェクト直下の設定が無い、または使う鍵が1つも指定されていないならば、システムは SSH 転送なしで起動し、指定方法を案内しなければならない(起動を止めない) |
| FR-env-04-5 | 境界値 | IF 指定された鍵ファイルが存在しないならば、システムは当該の鍵を警告してスキップし、残りの鍵で起動を続行しなければならない |
| FR-env-04-6 | 異常系 | IF agent ソケットの位置に壊れた残骸が存在するならば、システムはそれを自動で除去し、除去できない場合も起動を止めず、手動での対処方法を案内しなければならない |
| FR-env-04-7 | 異常系 | IF 端末を持たない環境でプロジェクト直下の設定が無いならば、システムは対話選択を行わず、**使う鍵が空である設定を書き出して**起動を続行しなければならない |
| FR-env-04-8 | 境界値 | WHERE agent の転送に中継のポート番号を使う環境(macOS)で、そのポート番号がホスト側から指定された場合、IF 指定された値が 1〜65535 の整数でないならば、システムは**その指定を採用してはならず**、受理できない値であることと受理する範囲を表示したうえで、**SSH 転送なしで起動を続行**しなければならない(起動を止めない。**「SSH agent 転送が有効である」と読める表示を出してはならない**。指定の手段は 02 の契約が定める) |
