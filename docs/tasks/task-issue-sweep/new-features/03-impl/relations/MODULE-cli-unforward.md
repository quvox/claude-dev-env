# MODULE-cli-unforward ポートフォワードの解除

## 目的

`MODULE-cli-forward` が作った中継コンテナを個別に取り消す(FR-env-06)。ホスト側ポートを
開けっぱなしにしないための対の操作である。

## 処理の流れ

1. 第1引数(`<cport>`)が**空または未指定なら**使い方を表示して `exit 1`。**それ以外の検証は行わない。**
2. `MODULE-cli-common-container-name` で対象コンテナ名を決める(第2引数 `NAME` があればそれを優先)。
3. `MODULE-cli-common-container-exists` で `fwd-<name>-<cport>` の存在を確認する(**停止中も含む**)。
4. 存在すれば `docker rm -f fwd-<name>-<cport>` で削除し、結果を表示する。存在しなければ
   その旨を表示して **0 で終わる**。

## 呼び出され方

- 契機: 利用者が `claude-dev unforward <cport> [NAME]` を実行したとき。
- 前提条件: なし(本体コンテナが停止していても中継コンテナは消せる)。
- 引数:

| 引数 | 型 | 必須 | 実装が行う検証 | 受理/拒否と結果 |
|---|---|---|---|---|
| `<cport>` | 文字列(整数を想定) | 必須 | **空文字・未指定かどうかだけ**を見る | 空・未指定 → 使い方を表示して `exit 1`。**それ以外はすべて受理**し、コンテナ名の一部としてそのまま使う |
| `NAME` | 文字列 | 任意 | 検証しない | 省略時はカレントディレクトリ名を小文字化し `[a-z0-9._-]` 以外を `-` に置換した値 |
| 第3引数以降 | — | — | — | **黙って無視する** |

**`<cport>` の境界値の実際の扱い**(検証が無く、名前の文字列一致だけで対象を決める):

| 入力 | 実際の結果 |
|---|---|
| 空 / 未指定 | 使い方を表示して `exit 1`(唯一の自前エラー) |
| `0` / 負数 / `65536` 以上 / 非数値 | そういう名前の中継コンテナは、**同じ値で `forward` を実行していない限り**存在しないので、「ありません」と表示して **0 で終わる**(エラーにならない) |
| 先頭ゼロ(`0080`) | `fwd-<name>-0080` だけを消す。**`fwd-<name>-80` は残る**(`forward 0080` で作ったものと対になる) |
| 大文字を含む `NAME` | 名前が一致しないため「ありません」と表示して 0 で終わる(コンテナ名は常に小文字) |

- 認可: CLI を実行できるホストユーザ。

## 連携先と連携内容

### MODULE-cli-common-container-name

- 何のために呼ぶか: 中継コンテナ名の決定。 / 何を渡すか: なし。 / 何を受け取るか: コンテナ名。
- **失敗したときどうなるか**: 想定されない。

### MODULE-cli-common-container-exists

- 何のために呼ぶか: 削除対象の有無を判定するため。 / 何を渡すか: `fwd-<name>-<cport>`。 / 何を受け取るか: 終了ステータス。
- **失敗したときどうなるか**: 「無い」と判定され、削除せずメッセージだけ出す。

## 戻り値・副作用

| 種別 | 内容 |
|---|---|
| 戻り値 | 0 |
| 永続化 | コンテナ `fwd-<name>-<cport>` の削除(占有していたホストポートが解放される) |
| 発火するイベント | なし |
| ログ | 標準出力へ解除結果 |

## 異常系

| 条件 | 実際の振る舞い | 呼び出し元への影響 |
|---|---|---|
| `<cport>` が空・未指定 | 使い方を表示して `exit 1` | 利用者が引数を付け直す |
| 対象のフォワードが無い(綴り違いを含む) | 「ありません」旨を表示して 0 で終わる。**綴り違いと本当に無い場合を区別しない** | 利用者は解除できたと誤解しうる |
| 対象が停止状態で残っている | `docker rm -f` で削除する(稼働中と同じ扱い) | なし |
| `docker rm -f` が失敗した(daemon 停止等) | `set -e` により非0終了する。**日本語の案内は出ない** | 利用者は docker の状態を確認する |

## 既知の制限

| 制限 | 影響 | 関連 issue |
|---|---|---|
| ポート単位でしか解除できない | まとめて解除したい場合は `stop` を使う | なし(閾値の外: 観測可能な被害が無い) |
| 対象が無い場合と入力を誤った場合を区別しない | 綴り違いでも「ありません」と出て 0 で終わるため、解除できたと誤解しうる | なし(閾値の外: 残っているフォワードは `claude-dev ports` の出力に現れる=**気づける手段がある**) |
