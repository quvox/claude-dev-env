## D0-sec-06 エージェントの隔離モデルは単一コンテナ同居型とする

- 区分: 決定
- 決めた日: 2026-07-30
- 内容: コンテナ内で動くすべてのプロセスは同一コンテナ・同一ファイルシステムを共有し、
  プロセスごとに個別隔離しない。**隔離境界はコンテナ/ホスト間にのみ置く**。
- 理由: 信頼できる社内開発用途に限定するという前提のもとでの割り切り。プロセスごとの隔離は
  実装・運用コストが高い。この前提は下流の全判断(Codex サンドボックスの扱い・confinement を
  緩めない方針)の根拠になっている。
- 却下した案: microVM 等によるプロセス単位の個別隔離 — 実装・運用コストに見合わない。
  個別隔離が要る用途は別構成(Docker Sandboxes 等)で検討する。
- 関連: RQ-env-01 / NFR-sec-01 / request.md「やらないこと」1
