## D0-orch-07 通知の失敗許容

- 区分: 委任
- 決めた日: 2026-07-30
- 委任範囲: 通知(Slack・フック)の送信に失敗したときに、呼び出し元をどう扱うか。重複通知をどう抑えるか。
- 制約(ガードレール): **通知の失敗で実行を止めないこと**(通知は補助であり、実行の可否を左右させない)。
  失敗を握りつぶす場合でも、利用者が状況を追える手段(ログ)を残すこと。
- 報告義務: 決めた内容を該当機能の「実装上の判断」表に `D0-orch-07` と共に記録する
