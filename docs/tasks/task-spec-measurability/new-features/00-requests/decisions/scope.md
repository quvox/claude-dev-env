## D0-scope-06 既存実装から仕様を起こすときの表現の食い違いの穴埋め

- 区分: 委任
- 決めた日: 2026-07-30(**2026-08-05 に委任範囲の書き方を対象ファイルによる限定へ改めた**。
  範囲そのものは広げていない)
- 委任範囲: **`docs/03-impl/relations/` と `docs/03-impl/contracts/` の散文**について、
  旧ドキュメントとコードで表現が食い違う点を、**コードを正**として記述すること。
- 制約(ガードレール): 次のいずれかに当たる食い違いは**委任範囲外**である
  (黙ってどちらかに寄せず、事実を報告して人間に問う)。
  1. 01 の受け入れ基準の意味が変わるもの
  2. 契約(`CTR-*`)の項目・型・エラー・列挙値が変わるもの
  3. 観測可能な振る舞い(利用者に見える出力・終了コード・作成/削除される資源)が変わるもの
  4. `docs/00-requests/` `docs/01-requirements/` `docs/02-design/` の本文
     (対象は 03 の散文だけであり、上流の層は範囲に含まない)
- 報告義務: 穴埋めした箇所をタスクの調査メモに残す
- 関連: `docs/issues/` / `D0-scope-07`(同じ委任を対象ファイルで限った先例)
