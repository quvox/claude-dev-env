## AC-08 プロジェクトごとの環境変数がコンテナ内のツールに見える

- 対応要求: RQ-env-07
- 前提: 初回セットアップが済んでいる。あるプロジェクトで、そのプロジェクトでだけ使いたい値
  (接続先の URL、社内サービスのトークン、動作を切り替えるフラグ)がある。
- 操作:
  1. プロジェクトディレクトリに env ファイルを作り、`名前=値` の形で値を書く。
  2. そのプロジェクトの `.claude-dev.yaml` に、その env ファイルの場所を書く。
  3. `claude-dev start` を実行する。
  4. 立ち上がった端末の中で、書いた名前の環境変数を表示する。
- 期待される結果: 書いた値がそのまま見える。コンテナ内で動かすツール(ビルド・テスト・
  エージェント CLI)からも同じ値が見える。**env ファイルは版管理の追跡から外れており**、
  リポジトリを共有しても値は相手に渡らない。別のプロジェクトのコンテナには、この値は見えない。
  **env ファイルに本システムが使う名前を書いた場合は、その1件だけが採用されず、
  採用しなかった名前が表示されたうえで起動は続く。**
- こうなったら不合格: 書いた値がコンテナの中で見えない / 別のプロジェクトのコンテナに値が漏れる /
  **env ファイルが版管理の追跡に入り、秘密の値がリポジトリへ入る** /
  **本システムが使う名前を書くと、それが差し替わってしまう** /
  env ファイルが無いことを理由にコンテナの起動そのものが失敗する。
