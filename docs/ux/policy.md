# デザインの基調

## トーン

本システムの UI はターミナル主体である。利用者との接点は「ホスト CLI のコマンド体系」だけで、
Web GUI を持たない(この判断とその理由は `docs/02-design/system.md` の
`### DSN-ui-01 UI はホスト CLI に限り、Web GUI を持たない` が持つ)。
noVNC でブラウザ確認を提供するが、これは本システムのアプリ UI ではなく、
利用者が開発中の Web アプリを見るための窓である。

## 色・余白・文字サイズの段階

本システムは色・余白・文字サイズを指定せず、端末の既定に従う。段階を持たない。

## 部品の流儀

- 前提不足(未セットアップ・未認証・設定ファイルが無い)は、止めずに次の操作を案内する。
  止めざるを得ない場合は、原因と復旧手段を日本語1行で示してから終了する。
- 端末が対話的でない場合は、選択を求めずに既定値で進む。

## 画面を使える手段(BR-13)

- 水準を定める条項: `FR-env-01-40`(すべての操作をキーボードだけで完了でき、結果と状態を文字で示し、色や文字の大きさだけで意味を伝えない)
- 適用しない範囲と理由: 支援する道具に読める名前と状態 — 本システムの画面は端末へ出す文字だけで、項目の名前と状態は
  その文字そのものである(端末と読み上げの道具の側の機能に従う)。noVNC で見るブラウザ画面は利用者が開発中の
  Web アプリの窓であり、本システムの画面ではない(「トーン」の節)
